## A0. Host-terminal band (v0.6.9)
- [ ] After updating **and restarting `dejimad`**, the footer shows **`[/] terminals`** with no flag (host terminals are now on by default).
- [ ] `/` opens/focuses the pinned host-terminal band; `t` adds a new one; `?` help **headlines `/`** (not `t`).
- [ ] If you disable it (`dejimad --host-terminals=false`), `/` and `t` print a **readable, non-truncated** note (no `…`) explaining it's off.

## A. Agents-by-name (v0.6.8 — owner is waiting on this)
- [ ] Approvals overlay (`V`) shows agent **names**, not ids: `janus/planning → deploy → starship/coder`.
- [ ] A **cross-island** message: `dejima msg poll` on the recipient shows the sender as `sourceIsland/name` (not a bare id). Same-island still shows the id.

## B. Usage signals (v0.6.7)
- [ ] An island near its memory cap shows **`mem NN% ⚠`** on its row (amber ≥75%, red ≥90%); a healthy fleet stays quiet.
- [ ] Island detail: mem/cpu **%-of-limit**, disk **%-of-cap**, and a **health** line only if it OOM'd / container-restarted.
- [ ] A Claude-Code agent's detail shows **`usage: … tokens · $…`** (or `n/a — no usage reported yet`); cost hidden for an unpriced model.

## C. Name-collision UX (v0.6.7)
- [ ] Add or rename an agent to a name that's **taken** → notice: **"'build' was taken — named it build-2"**.

## D. Wake-on-message (v0.6.5 — the one functional unknown)

## E. Tab titles (v0.6.4)
- [ ] Opening an agent titles the terminal tab **`island/label`** (e.g. `dejima/TUI`), not `island/a2`.

## F. Visual identity / keys (v0.6.2–v0.6.3)

- [ ] `>` opens the in-island shell; Enter on an island opens its agents; the action-gate `[a]` on a destructive row **demands a typed `y`**; long confirm prompts wrap.
