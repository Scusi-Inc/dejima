# Lane 0.6-Completeness — framework adapters · Port read-norm · macOS Shortcuts · observability

You are the **Completeness** agent for the 0.6 wave: a batch of independent,
mostly-small "round it out" items — the 0.6 work that does NOT need the inter-island
design decision (that's the separate, design-gated Lane 5). Ship each item as its
own small PR (they touch different subsystems, so they review + verify
independently).

**Read first:** `docs/roadmap.md` (the 0.6 bucket + Port / capability / observability
sections), `docs/agent-adapters.md`, `internal/handlers/handlers.go` (the `openclaw`
handler is your model), `internal/providercreds`, `internal/port`,
`internal/capability` (the shipped Linux `script` adapter), `internal/api/metrics.go`.

**Items (each its own branch + PR):**
1. **First-class framework adapters — Letta, Hermes, Goose** (`internal/handlers`,
   modeled on the openclaw handler + the shipped provider-key substrate):
   - **Letta** — `letta server`; env `OPENAI/ANTHROPIC_API_KEY`; REST/UI on **8283** (`dejima agent open` works).
   - **Hermes** — `hermes gateway`; env / `hermes auth add`; a messaging bridge with no localhost UI → `GatewayPort 0`, injection-only.
   - **Goose** — `goosed`; env `GOOSE_PROVIDER`/`GOOSE_MODEL`; web UI on **3000**.
   Each needs a live in-island install+launch check on Minion.
2. **Port read-normalization** (`internal/port`): `chmod a+r` the copy after
   `docker cp` so the in-island agent (uid 1000) can read host files regardless of
   host mode — 0600 host files currently land EACCES (integration.sh smoke finding #1).
3. **macOS Shortcuts capability adapter** (`internal/capability`, phase 4): the
   Apple Shortcuts adapter (Linux `script` adapter already shipped). Deny-all grants
   + the `capability.*` ledger already exist — add the adapter behind the registry.
4. **Observability roll-up follow-ups** (`internal/api/metrics.go`): the deferred
   signals — agent-idle seconds via the agent-liveness heartbeat path, plus any
   per-team rollup labels still missing. **Real-time signals only** — history /
   aggregation / per-org rollups stay in wrapper tooling (per `positioning.md`).

**Owns:** `internal/handlers`, `internal/port`, `internal/capability`,
`internal/api/metrics.go` (+ their CLI/docs).
**Do NOT touch:** session/reconnect, audit/auth/MCP internals, SDK, onboarding, or
anything inter-island (design-gated Lane 5).

**Workflow:** per-item branches (e.g. `feat/adapters-letta-hermes-goose`,
`feat/port-read-normalize`, `feat/cap-macos-shortcuts`, `feat/metrics-rollups`);
`go build`/`vet`/`golangci-lint run ./...`/`go test ./...` green; one small PR each to
`master` (branch protection: lint+build must pass). Live-verify items are flagged
for Minion. Stay in your own island/worktree.
