# Lane 0.5-Onboarding — "the easiest way to run agents on a Mac mini"

You are the **Onboarding** agent. Goal, stated bluntly: make Dejima **the easiest,
tightest, most foolproof way to turn a Mac mini into a personal AI-agent server** —
fresh Mac mini → working Dejima host in one command, ~5–20 min, auto-doing
everything possible and only *instructing* for GUI-only steps. This is the 0.5
headline + the competitive lever (rivals are all easy to start; we must be easier).

**Read first:** `docs/host-provisioning-plan.md` (the full plan), `docs/roadmap.md`
(Versioning map → 0.5; the v1.x onboarding items), `cmd/dejima/onboard.go`,
`cmd/dejima/main.go` (`service install` flags), `internal/service/`.

**Scope (in priority order):**
1. **`dejima onboard --provision-host` wizard** (macOS) — walk a fresh Mac mini
   through: **Energy Saver → never sleep** (critical — a sleeping mini drops every
   session; `sudo pmset -a sleep 0 disablesleep 1` / `caffeinate`), enable auto-login
   (so LaunchAgents survive reboot), Homebrew, Tailscale (install + `tailscale up`),
   Docker (Desktop/OrbStack/colima) + the VM-memory right-size (`dejima doctor --fix`),
   then hand off to the existing onboarding (`service install --system --tcp :7273
   --token-tcp 127.0.0.1:7274 --audit`). Auto-do what's scriptable; print clear
   instructions for GUI-only steps; idempotent (re-runnable).
2. **Adaptive first-run prompt** — detect server vs client context (Docker + dejimad
   present? `DEJIMA_HOST` set? daemon reachable?) and ask the context-specific y/n.
3. **Connection-failure offer** — on first "daemon unreachable" with `DEJIMA_HOST`
   set, offer one-shot troubleshooting help.
4. **`docs/mac-mini-host-setup.md`** — a screenshots-and-paragraphs companion for
   people who'd rather read than be wizard'd.

**Owns:** `cmd/dejima/onboard.go`, new onboarding/provisioning helpers, the new
doc. Coordinates (append-only) on `service install` flags in `cmd/dejima/main.go`.
**Don't touch:** the session/reconnect code, SDK, audit/auth/MCP internals.

**Verify on Minion (this is host-specific — needs the real Mac):** run
`dejima onboard --provision-host` on a Mac and confirm a clean fresh-host path,
sleep is disabled, the service comes up with `--audit`, and a reboot leaves the
daemon reachable with no interactive login.

**Workflow:** your own worktree on branch `feat/onboard-provision-host`; `go build`
/ `go vet` / `golangci-lint run ./...` / `go test ./...` green; PR to `master`
(branch protection: lint+build must pass); commit only your hunks.
