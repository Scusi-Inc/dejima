What people use Dejima for

One runtime, a few different jobs. Whatever you're here for, the foundation is the same: agents contained on hardware you own, with brokered host access and an audit trail.

Keep AI agents off your private files

Deny-all by default. An agent touches only the folder you grant, read-only, and every crossing is logged.

Give your team a shared agent host

One box you own, several people, role-scoped tokens, a shared audit trail. No per-seat SaaS.

Run agents on a Mac mini

Turn a quiet mini into an always-on agent server in five minutes. Claude Code, Codex, OpenClaw, contained.

Self-host agents in your own cloud

A VM in your own account instead of a managed sandbox. Your code, your egress, no per-second meter.

Build products on Dejima

One HTTP and WebSocket API for isolated, managed agents. Target it from any language with the SDKs.
